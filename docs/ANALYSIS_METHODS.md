# 分析方法 (ANALYSIS_METHODS)

算法版本 `heritage-analysis-v1` ｜ 数据版本见各输出文件 ｜ 全部实现于 `data-pipeline/scripts/analysis.py`, 重跑即复现。

公开发布范围已冻结为湖北省。前端分析资产由脚本默认从 13 处湖北点位生成；全国结果仍保留在处理目录，只用于内部追溯，不进入默认 Agent 查询。

## 1. 核密度估计 (KDE)

- 输入: 公开包为 13 处湖北遗产 WGS84 坐标 → Albers 等积圆锥投影(lon0=105°E, lat1=25°N, lat2=47°N, Krassovsky 1940 椭球; 正逆往返误差 <1e-8°, 单元测试覆盖)。
- 核: 高斯; 带宽: Silverman 规则 `0.9·min(σx,σy)·n^(-1/6)`, 下限 50km —— 本次数据实际取值 **≈240km**(全国尺度点稀疏, 小带宽会产生碎片热点)。
- 网格: 10km; 湖北输出实际为 67×59 栅格，带宽下限 50km；输出为密度归一化 5 档蓝-黄-红透明 PNG + `extent_wgs84_corners`(Albers 逆投影得到的 WGS84 四角, 供 MapLibre ImageSource 叠加)。
- **解释边界**: 密度图只描述"点位空间分布强度", 高值区=遗产密集区, 不构成任何成因结论。

## 2. 平均最近邻 (ANN)

湖北包的 ANN 只作为描述性指标：样本量为 13，不用于推断全省工业遗产总体，也不作历史因果解释。

- 湖北结果：观测平均最近邻距离约 20.84km，期望随机距离约 30.65km，**R=0.6799**，z=-2.21，属于描述性聚集趋势，不作因果解释。
- 注意: 研究区取点集凸包, R 对研究区定义敏感; 已在输出 JSON 中声明。

## 3. 全局 Moran's I (省级计数)

湖北公开范围只有一个省级单元，省级 Moran's I 不适用。输出保留 `I=null` 和原因说明，避免把单元不足误读成“没有空间自相关”。

- 湖北结果：只有 1 个省级单元，`I`、`z` 均为 `null`，不计算省际空间自相关。
- **解释边界**: 全局指数不能定位局部聚集; 计数变量受省域面积/工业规模影响; 如需定位湖北省内局部聚集，应补充城市/县域单元与可靠边界数据。

## 4. 描述统计

批次/行业/省份/核心物项类别分布(`batch_stats.json`), 前端分析面板直接消费。

## 5. 可复现性

```bash
python data-pipeline/scripts/analysis.py   # 默认重算湖北分析(依赖 processed/heritage_sites.json)
python -m pytest data-pipeline/tests -q    # 47 项数值/边界回归测试
```

输出元数据(`analysis_results.json`)包含数据版本、算法版本、投影参数、输入输出清单与时间戳; 缓存 key 约定: 前端按 `data_version + 参数` 命名, 参数变更即失效。

## 6. 区位关联分析框架(预留)

当前数据集不含历史铁路/河流/港口/矿产/老工业基地边界等外部图层, 因此**未实现**距离/叠加类区位分析, 避免拼凑低质量数据宣称因果。框架已预留: 省级统计图层与主表结构可直接扩展 `heritage_geometries` 与参照图层; 获得权威参照数据(如历史铁路网)后, 按 §1 同样的"投影→计算→参数入档"流程接入即可。
