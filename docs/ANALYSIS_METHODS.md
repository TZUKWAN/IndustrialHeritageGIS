# 分析方法 (ANALYSIS_METHODS)

算法版本 `heritage-analysis-v1` ｜ 数据版本见各输出文件 ｜ 全部实现于 `data-pipeline/scripts/analysis.py`, 重跑即复现。

## 1. 核密度估计 (KDE)

- 输入: 263 处遗产 WGS84 坐标 → Albers 等积圆锥投影(lon0=105°E, lat1=25°N, lat2=47°N, Krassovsky 1940 椭球; 正逆往返误差 <1e-8°, 单元测试覆盖)。
- 核: 高斯; 带宽: Silverman 规则 `0.9·min(σx,σy)·n^(-1/6)`, 下限 50km —— 本次数据实际取值 **≈240km**(全国尺度点稀疏, 小带宽会产生碎片热点)。
- 网格: 10km; 输出: 密度归一化 5 档蓝-黄-红透明 PNG(569×484) + `extent_wgs84_corners`(Albers 逆投影得到的 WGS84 四角, 供 MapLibre ImageSource 叠加)。
- **解释边界**: 密度图只描述"点位空间分布强度", 高值区=遗产密集区, 不构成任何成因结论。

## 2. 平均最近邻 (ANN)

- 观测平均最近邻距离 d̄=45.35km(凸包面积 A≈8.43×10¹² m², n=263)。
- 期望(随机) E[d]=0.5/√(n/A)≈89.5km; **R = d̄/E[d] = 0.507 < 1**; z = −15.31(|z|>1.96)。
- 结论: 全国尺度上遗产点呈**显著聚集**格局(印证"工业沿重要工业走廊与城市群集聚"的常识性认识, 但本指数本身不指认聚集位置)。
- 注意: 研究区取点集凸包, R 对研究区定义敏感; 已在输出 JSON 中声明。

## 3. 全局 Moran's I (省级计数)

- 单元: 31 个省级行政区(不含港澳台, 名单无此类记录); 变量: 各省遗产数量。
- 空间权重: KNN k=4(基于省级中心点), 二元行标准化 —— 采用 KNN 而非面邻接的原因与局限已写入输出。
- 结果: I = 0.0132, E[I] = −0.0333, **z = 0.43** → 省级层面**无显著空间自相关**。解读: 遗产数量在省级之间的高低分布大体随机(部分省份高更多由单体记录密集驱动, 而非连片高值)。
- **解释边界**: 全局指数不能定位局部聚集; 计数变量受省域面积/工业规模影响; 如需定位高-高聚集应做 LISA/Getis-Ord(本版本未实现, 输出中已声明)。

## 4. 描述统计

批次/行业/省份/核心物项类别分布(`batch_stats.json`), 前端分析面板直接消费。

## 5. 可复现性

```bash
python data-pipeline/scripts/analysis.py   # 重算全部分析(依赖 processed/heritage_sites.json)
python -m pytest data-pipeline/tests -q    # 47 项数值/边界回归测试
```

输出元数据(`analysis_results.json`)包含数据版本、算法版本、投影参数、输入输出清单与时间戳; 缓存 key 约定: 前端按 `data_version + 参数` 命名, 参数变更即失效。

## 6. 区位关联分析框架(预留)

当前数据集不含历史铁路/河流/港口/矿产/老工业基地边界等外部图层, 因此**未实现**距离/叠加类区位分析, 避免拼凑低质量数据宣称因果。框架已预留: 省级统计图层与主表结构可直接扩展 `heritage_geometries` 与参照图层; 获得权威参照数据(如历史铁路网)后, 按 §1 同样的"投影→计算→参数入档"流程接入即可。
