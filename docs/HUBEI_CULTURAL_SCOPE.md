# 湖北工业文化遗产范围与数据说明

本版本的国家遗产主表包含湖北省 13 处国家工业遗产；同时维护 `inventory.json` 全省扩展底册，当前纳入377条有省级、市级、文保/历史建筑、行业、档案或研究来源的对象和线索（353条来源确认、24条来源线索）。国家工业遗产是官方认定身份；“工业文化遗产”是本项目在官方认定、地方名录和文化研究证据之上建立的分层研究与展示层，不能把不同认定层级混为一个字段。

## 文化档案的六个问题

每处遗产在 `src/data/heritage/cultural.json` 中都有一份文化档案：

| 维度 | 产品中回答的问题 | 证据要求 |
|---|---|---|
| 文化载体 | 哪些建筑、设备、产品、档案或景观承载了遗产？ | 优先使用工信部核心物项和正式馆藏目录 |
| 技术与技艺 | 哪项生产技术、工程方法或传统技艺可以被解释？ | 事件、技术档案、考古报告或官方展陈 |
| 组织与人物 | 哪些组织、人物和劳动协作关系构成遗产？ | 厂志、地方志、档案、正式机构资料 |
| 社会记忆 | 哪些产品、空间、事件和口述材料进入地方记忆？ | 口述史、影像、展陈、报刊或档案 |
| 保护与利用 | 当前是否仍生产、运行、开放或被改造利用？ | 管理机构、企业或政府最新公开资料 |
| 资料边界 | 哪些内容仍然缺证？ | 必须明确写出待补证项 |

`documented` 表示已有事件或公开来源支持，`baseline` 表示已经完成官方核心物项的文化载体解释，但仍有关键维度需要公开材料或田野调查补证。所有研究解释都带 `evidence_type` 和 `evidence_level`，前端会直接显示来源 ID。

## 数据范围与发布包

- `src/data/heritage/sites.json`：13 处湖北点位的首屏字段。
- `details.json`、`events.json`、`relations.json`、`profiles.json`：湖北范围的详情、时间线、关系和历史档案。
- `cultural.json`：13 处文化档案，当前 5 处为 `documented`，8 处为 `baseline`。
- `inventory.json`：国家名录之外的湖北扩展底册，当前377条（353条来源确认、24条来源线索）；记录状态、名录层级、地市、行业、来源 ID、待补证边界，以及新增对象的四项文化证据摘要。
- `sources.json`：湖北公开包实际引用的来源；本轮构建为276个来源；底册原始来源键为286个，涵盖国家主表、文化档案和扩展底册，官方批次/文保公告为 A 级。
- `analysis/`：以 13 处湖北点位生成的 KDE、ANN 和描述性统计；单省范围不计算 Moran's I。
- `python-backend/opengis_backend/data/heritage/`：与前端完全相同的数据切片，保证 Agent 与地图使用同一事实版本。

全国原始名单与完整处理结果仍保留在 `data-pipeline/raw`、`interim` 和 `processed`，用于追溯和重新切片；它们不属于公开产品的默认查询范围。扩展底册第一轮目标为170条，当前已达377条，后续继续纳入县市级普查、三线/央企/行业名录、文保与历史建筑中的工业对象，以及经来源核实的未认定候选。第二十一轮补入天门供销、码头、商号、搬运、水塔、老图书馆等历史建筑对象、鄂州原市麻纺厂规划片区、神农架开发建设声像档案，并补强仙桃1979街区、潜江五七油田会战指挥部、黄冈铝业社区与神农架林业历史馆；第二十二轮新增潜江油田职业技术学校旧址、盐化工业园区工业文化景观、广华职工社区与油地融合公共空间、潜江市石油化工厂历史谱系并登记仙桃/潜江四普覆盖依据；第二十三轮新增十堰原东风59厂、62厂、6264厂、房县恒达/华球纺织厂、原东风54厂片区和东风小康一工厂旧厂房；第二十四轮新增仙桃原第三服装厂旧厂房、三伏潭无纺布厂区、大垸子—沙湖泵站老旧水利设施群、蒲纺一中旧厂房改建教学楼、二三四八工业文化展览馆和柏墩生甡川砖茶厂清代老厂房；第二十五轮新增神农架伐木时代木材运输路、随州老火车站和黄冈地区缫丝厂历史谱系线索；第二十六轮新增2250kV/9000kVA工频试验成套装置、青山热电厂1号汽轮机转子、青山热电厂首台发电机铭牌、葛洲坝水利枢纽、武钢一号高炉和航天066导弹基地的“共和国印记”实物与保护利用案例文化景观，并补强老虎洞水电站和大冶铁矿群国家专题案例来源；第二十轮补入葛店化工厂一号楼和机械厂四普新发现、恩施/利川烟叶复烤厂活化对象、鹤峰中营红三军枪炮局与被服厂、恩施三星洞地下军工厂、巴东金果坪枪炮局、鹤峰五里坪革命生产性组成项；正式文保、未定级普查对象、规划对象、研究候选和工业文化景观均保持分层。第十九轮及此前各轮补入的新屋李铸造、二汽、文字605/603、石花酒厂、云盖寺绿松石矿、管窑基地、孝感麻糖、铁路/水利/矿冶/茶业/档案和工业金融节点继续保留。 第二十七轮新增黄冈城市更新工业对象、补强随州塑料三厂来源并校正神农架林业历史馆来源元数据。 第二十八轮补入十堰46厂博物馆项目和模具、车轮、泵业文化资料线索，补强44厂具体物项并登记100处不可移动/300项可移动汽车工业文化遗产普查规模。 第二十九轮补入随州缫丝厂区—缫丝社区工业文化景观，以城市更新与企业社区来源补足厂区、职工社区和社会记忆链条。

## 再生产与验收

在项目根目录执行：

```powershell
python data-pipeline/scripts/analysis.py
python data-pipeline/scripts/export_frontend.py
python -m pytest data-pipeline/tests -q
npm run typecheck
npm test -- --run
npm run build
```

如需显式切换范围，设置 `ANALYSIS_PROVINCE` 或 `HERITAGE_PROVINCE`；`ALL`/`全国` 只用于内部全国分析，不会改变默认湖北发布包。

## 资料使用边界

官方名单和公告按其公开条件引用；外部网页只保存题名、链接、访问日期和必要摘要，不把受版权保护的全文复制进数据包。涉及军工、企业内部档案、配方和未公开口述材料时，只有在取得公开或授权来源后才可把状态从 `pending` 改为 `documented`。
