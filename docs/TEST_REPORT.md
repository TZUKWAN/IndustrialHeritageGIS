## 4. 已知问题与限制

1. **底图瓦片依赖外网**: 本沙箱环境对 OSM/Carto 瓦片服务器间歇不可达, 底图可能黑屏; 点位/分析/全部功能不受影响。生产环境正常联网即有底图。
2. **资料覆盖**: 57/263 处有已核实史实(试点13+波次2的44处, 覆盖全部第1批与第2-7批代表性遗产), 其余 206 处档案为诚实的"待补"状态; 扩大覆盖只需按 DATA_PROVENANCE §2 的采集格式追加 enrichment 文件并重跑 `build_enrichment.py`。
3. **地理编码精度**: 名单仅含行政区划地址, 区县中心点为可诚实达到的最高精度(逐条标注 precision, 19 处标记待复核)。
4. **LISA/Getis-Ord 未实现**(全局 Moran 不显著, 局部指标意义有限); 区位关联分析待权威参照数据, 均已在 ANALYSIS_METHODS 声明。
5. 上游 28 条 eslint warning(exhaustive-deps 等)保留未动 —— 不影响运行, 修复涉及上游行为变更, 超出本任务"最小侵入"边界。
