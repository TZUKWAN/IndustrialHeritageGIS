## 当前限制

1. 13 处中 5 处文化档案为 `documented`，8 处为 `baseline`。`baseline` 已完成官方核心物项的文化载体解释，但社会记忆、人物/组织或保护利用等部分仍标记待补证，不能在发布说明中称为同等史料深度。
2. 坐标仍是名单地址对应的行政区中心点，公开包保留精度字段；它用于省域展示和描述性分析，不代表具体建筑物精确位置。
3. 底图依赖外部瓦片服务；底图不可达时，内置点位、文化档案、来源和分析数据仍可用。
4. Lint 的 28 条 warning 来自上游依赖代码，本次变更没有新增 warning；未擅自扩大修复范围。
